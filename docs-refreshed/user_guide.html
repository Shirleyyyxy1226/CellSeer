User guide

Projects, ingest, six dashboard tabs, protocols, annotations, export.

Projects & the home screen

A project is one cycling campaign. The home screen lists projects with cell/dataset/chemistry counts. Search, sort, or + New project. Card title → upload page; Dashboard → analysis (greyed until data exists).

Loading data

Two upload tiles per project:

TileAcceptsWhat it carries
Metadataspreadsheet (.xlsx / .csv)One row per cell: chemistry, separator, spacer, masses, batch, electrolyte — the experimental conditions
Cycling datacycler exports (Neware .xlsx, …) · multi-fileThe time-series voltage / current / capacity traces, one file per cell

Drag or click to upload. Metadata upload may ask which column links to cycling files. Readiness shows when metadata + at least one cycling file exist. Supported formats: GET /api/upload/loaders (add loaders in backend/loaders/ — Developer docs). Extensions: .xlsx, .xls, .csv, .mpt, .mpr. Max 512 MB per file. Data stored as Parquet with SHA-256; deletes are soft (tombstone).

DIGIBAT integration

Pull cells from a DIGIBAT robot lab instead of manual upload. Connect once, map a collection to a project. Sync is incremental (changed files only). Status shown per project. See Developer docs for API detail.

Dashboard layout

Six tabs, broad → narrow. Selection persists across tabs; active tab in URL (?tab=).

TabScopeAnswers
Hierarchy Treewhole library, structuralHow is my library organised? What conditions exist?
Master Plotwhole campaign, at a glanceWhich condition wins? Which cells failed?

Tree and Master Plot are full-bleed. Other tabs: resizable hierarchy sidebar + chart area. Column order saved per project.

Hierarchy Tree

Drag metadata fields in the order bar to nest cells. Search, expand/collapse, click leaf to select. Single: one cell or filter path. Multi: accumulate cells for GCD/differential overlays.

Master Plot

Campaign overview: four sub-views share a metric selector and KPI strip. Click a cell → Inspector (sparkline, drill-through). Colours: cathode hash — see Design language.

Sub-viewWhat it shows
HeatmapCondition rows; replicate tiles coloured by metric; pin conditions
RankingConditions sorted by cohort mean; ±1 SD whisker; replicate dots
TrajectoriesSmall-multiples grid: one panel per condition, capacity vs cycle (fetches per-cycle data when opened)
Parallel coordsDefault axes: Cathode → Separator → Spacer → Cycles → End capacity; click a line to select

Deep dive: Master Plot metrics (developer docs).

Rate Performance

Capacity vs cycle; C-rate steps shaded when a protocol is attached. Hierarchy sidebar picks cells. Charge / Discharge toggle in chart header. Drill into/up hierarchy levels. Optional voltage-vs-time inset (first N formation cycles, default 5).

GCD Plot

V vs capacity, one trace per cycle (blue ramp). Cycle filter (e.g. 1-3, 5, 10-15); Charge / Discharge / Both. Mini-panels: cumulative GCD, rate performance, CE when data exists. Specific-capacity axis when cathode mass known.

dV/dQ 3D

dV/dQ vs capacity (X = Q, Y = dV/dQ, Z = cycle). Profile and Evolution presets open 2D side panels. Cycle slider, Reset 3D, Charge / Discharge. >200 traces → confirm before WebGL render.

dQ/dV 3D

dQ/dV vs voltage — same layout and controls as dV/dQ.

Selecting & filtering cells

One selection across the app:

  • Hierarchy Tree — click node/leaf; Multi mode accumulates cells.
  • Master Plot — click tile, dot, or line; pin conditions.
  • Filters — Cathode / Separator / Spacer (dashboard-wide); Electrolyte / Protocol (Master Plot only).

Detail panel (right edge): metadata and annotations for selected cell(s).

Protocols

Segments cycles into phases (formation, rate test, main cycling) with C-rates. Attach via wizard or bulk templates. C-rate bands in Rate Performance. Protocol-gated Master Plot metrics (retention, CE, dQ/dV peak shift) show a lock and “needs a protocol” until at least one cell has segments attached; after attachment they show “Coming soon”.

Annotations & metadata

Detail panel: add notes and preset tags (Star, Anomaly, Failed) via PUT /api/cell-annotation/{cellId}. Edit allow-listed metadata inline; derived metrics (e.g. specific capacity) refresh.

Exporting figures

Right-click any chart for export options. Beyond PNG / CSV / Plotly-JSON, the Export ZIP option produces a self-contained reproducible bundle:

In the ZIPWhat it's for
the PNGthe figure as you see it
trace data (CSV + Plotly JSON)the exact points drawn
manifest.jsonprovenance: source cells, full-resolution API endpoints, view settings, timestamp
reproduce.pyregenerates the figure; --fetch-original re-downloads the original full-resolution data

Right-click any chart → PNG, CSV, Plotly JSON, or Export ZIP (self-contained bundle with reproduce.py).
