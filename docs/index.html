What CellSeer is

An open-source web app for browsing, comparing, and annotating high-throughput coin-cell campaigns:

ComponentWhat it isUse it when
Web appReact + TypeScript dashboard over a FastAPI + PostgreSQL + Parquet backendYou want to browse, compare and annotate a whole library interactively — hosted or local
Chart buildersFramework-free TypeScript Plotly builders (buildGcdFigure, etc.)Embedding CellSeer charts in another web app — see Developer docs
