Features overview

Product capabilities mapped to frontend modules and backend support. Tab-level detail lives in the Dashboard & plot guide; user-facing behaviour in User guide.

Dashboard

Six URL-addressable tabs in frontend/src/pages/Index.tsx (?tab=, default tree): hierarchy tree, Master Plot, rate performance, GCD, dV/dQ 3D, dQ/dV 3D. Per-cell scalars always from GET /api/master-plot/overview; per-cycle payloads lazy-loaded when a view needs them.

  • Hierarchy tree — mindmap filter and selection (features/hierarchy/)
  • Master Plot — heatmap, ranking, trajectories, parallel coords (features/masterPlot/)
  • Rate performance · GCD · differential 3D — Plotly dashboards with shared tree sidebar

Tab registry, hooks, endpoints, and controls: Dashboard & plot guide. Campaign metrics: Master Plot metrics.

Protocols

Two-step wizard (AttachProtocolDialog.tsx): SequenceStep → ApplyStep. Segment: { name?, cycleStart, cycleEnd (null=open), cRate }. Wire via toWireList() (strips React UUID).

  • Templates: GET /api/protocol-templates (builtins read-only; user templates by name)
  • Single: PUT /api/cells/{cell_id}/protocol; bulk: POST /api/cells/protocol/bulk
  • Protocol-gated Master Plot metrics → "needs a protocol" / "Coming soon" — Protocol attachment

Upload and ingest

  • Metadata spreadsheets → cell rows
  • Cycler files (Neware, BioLogic, Arbin) → Parquet + dataset rows
  • Background tasks tracked in upload_task table
  • Loader manifest at GET /api/upload/loaders

Full pipeline trace: Ingestion pipeline.

DIGIBAT sync

Admin page at /digibat and API under /api/digibat/* and /api/projects/{id}/digibat/*. CLI alternative: backend/scripts/sync_digibat.py. See DIGIBAT sync for provenance, soft-delete lifecycle, and schema details.

Annotations

Per-cell notes and JSON tag arrays via /api/cell-annotation/{cell_id}. Separate from metadata notes column on cell.

Export

frontend/src/lib/plot/exportUtils.ts bundles Plotly JSON, PNG, CSV, and reproducibility manifests into ZIP downloads from dashboard toolbars.

Home and projects

  • HomePage — project list, create/delete, DIGIBAT status snippet
  • ProjectDetailPage — project summary, readiness, link to dashboard
