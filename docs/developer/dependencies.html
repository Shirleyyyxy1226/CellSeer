Radix UI suite. The full set of @radix-ui/* primitives is installed: accordion, alert-dialog, aspect-ratio, avatar, checkbox, collapsible, context-menu, dialog, dropdown-menu, hover-card, label, menubar, navigation-menu, popover, progress, radio-group, scroll-area, select, separator, slider, slot, switch, tabs, toast, toggle, toggle-group, tooltip. These are consumed indirectly through shadcn/ui component wrappers.

frontend/src/charts

Lives at frontend/src/charts/ and is imported by the SPA via the Vite path alias @/charts (configured in vite.config.ts resolve.alias). No separate package.json or npm publish. Framework-free: Plotly trace construction and adapters under adapters/.

Previously named cellviz-lib; a top-level adapt.ts was removed in favour of adapters/normalizeCyclerDatasets.ts.

Notable internal modules:

  • frontend/src/lib/color/cellColorScheme.ts — chemistry colour assignment via DJB2 hash (used by dashboards and re-exported into plot builders)
  • frontend/src/lib/color/cycleColormap.ts — cycleColor(t) blue ramp and cellCycleColor(hex, t) cell tint ramp
  • charts/style.ts — re-exports colormap helpers (cellColor, cycleFadeColor, cycleColor, cellCycleColor) for plot builders

Embedded backend/compute

Not published to PyPI. Shares dependencies with the backend requirements file. Provides readers, cycling analysis, metadata parsing, and a CLI — overlapping conceptually with the root cellseer plotting package but serving server ingest rather than notebook plotting.
