Computation report

Formulas and methods for CellSeer analytical computations — traced from source. Gaps stated where the repo lacks primary literature.

1. Executive summary

CellSeer ingests cycler exports → Parquet + PostgreSQL, then computes per-cycle capacity, differential curves (dQ/dV, dV/dQ), campaign scalars (Master Plot), and plot traces (GCD, rate, differential).

  • Protocol-gated metrics: CE, retention, and dQ/dV peak shift show "needs a protocol" or "Coming soon" in the UI
  • Declared gaps: no cathode mass → no specific capacity (not interpolated)
  • Protocol segmentation: C-rate labels from attached protocol or ingest metadata
  • Replicate stats: condition cohorts carry mean, SD, CV%, t-based 95% CI on frontend
  • Server-side overview: scalars in Python (masterplot/overview.py); client adapts via summariesFromOverview

4.2 Rate performance

Backend (GET /api/rate-performance): per-cell aligned arrays — cycles, discharge/charge mAh, optional specific mAh/g, optional C-rates and protocol segments.

C-rate: protocol segments map cycle index → C-rate; open-ended segments extend to max cycle.

Frontend (ratePerfAggregation.ts): group by hierarchy level; single cell = raw series; multiple = cycle-aligned mean with min–max whiskers (not SEM).

4.3 Differential analysis (dQ/dV, dV/dQ)

ICA (dQ/dV vs V) and DVA (dV/dQ vs Q). Ingest + on-the-fly API share:

  1. Isolate charge/discharge by current sign (≥30 points for LEAN)
  2. Uniform capacity grid; LEAN bins (~180) with bin protection
  3. 5-point LEAN kernel (Feng et al. / PyProBE); self-repair on blow-up
  4. Alternatives: navani (Savitzky–Golay + spline) or raw (1000-point grid + numpy.gradient)
ImplementationDefault parametersOutput columns
backend/compute/analysis/cycling/differentiation.py method="lean" (default), lean_target_bins=180, 5-point _LEAN_KERNEL. Also navani, raw (n_bins=1000). dQ/dV [Ah/V], dV/dQ [V/Ah]
cellseer/src/cellseer/compute.py Mirrors backend LEAN (target_bins=180); optional navani/raw paths Stored as mAh V⁻¹ in frontend plots (unit scaling at display)
frontend/src/charts/plotting/dqdv.ts / dvdq.ts Visualisation only — reads precomputed or on-the-fly API payload. ~150 interpolation points in useDifferentialData for smooth curves. Peak = argmax of curve (findPeak); 2D and 3D Plotly figures

3D surface views

One scatter3d line per cycle. dQ/dV: X=V, Y=cycle, Z=dQ/dV; dV/dQ: X=Q, Y=cycle, Z=dV/dQ. Cycle colour via cycleFadeColor.

Camera presets (Profile / Evolution), wheel isolation, resize handle — see Surface3dPlot.

2D side panels

Cycle slider (defaults to latest); Profile = baseline + optional pinned refs; snaps to nearest cycle if typed value missing.

4.5 Hierarchy analysis

POST /api/hierarchy/analyse does not compute battery metrics. It:

  • Parses metadata CSV text.
  • Profiles each column (cardinality, coverage, numeric vs categorical, notes/replicate keywords).
  • Selects up to maxLevels hierarchy columns via heuristics (exclude row-id, leaf label, flag columns).
  • Builds a tree JSON, colour maps, and path→colour assignments for the mindmap UI.

GET /api/hierarchy runs the same pipeline on live PostgreSQL cell metadata for the active project.

4.6 GCD plots

From /api/cell-record/{id}; mirrors cellseer/gcd.py:

  • Discharge x from 0 (relative to qmax); charge from qmin
  • Cumulative mode chains segments along x
  • Downsample: max 2500 points/trace (stride)
  • Specific capacity when cathodeMassG present
  • Per-cycle colour via cellCycleColor; multi-cell uses dash/symbol discriminators
