Data platform & storage architecture

Imperial DataLab / DIGIBAT. CellSeer integrates with the DIGIBAT API for remote collection sync. The local storage model — PostgreSQL catalogue (project, cell, dataset) plus Parquet files under data_lake/ — was informed by Imperial DataLab's separation of collection metadata from file-backed datasets and provenance fields. CellSeer is an independent application; it is not an official DataLab product. See DIGIBAT sync and data model.

Software dependencies

The key third-party components CellSeer is built on. Full version pins are in Dependencies.

Backend

  • PyProBE-Data — Neware cycling file reading (.xlsx record sheets). Optional dependency; requires Python 3.11+. BioLogic (.mpt/.mpr) and Arbin exports are handled by native CellSeer readers.
  • FastAPI + Uvicorn — REST API server.
  • Polars / Pandas — tabular data processing in the ingestion pipeline and analysis layer.
  • Pydantic v2 — request/response validation.
  • PostgreSQL — cell catalogue (via CELLSEER_DATABASE_URL).

Frontend

  • React 18 + TypeScript 5 — UI framework and type system.
  • Vite 5 (with SWC) — build tool and dev server.
  • Plotly.js (plotly.js-strict-dist-min) — all interactive charts: GCD, rate performance, differential (dQ/dV, dV/dQ, 3D surface), voltage-time, and Master Plot overlays.
  • TailwindCSS 3 — utility-first styling; custom HSL colour tokens, Inter/Lora/Space Mono fonts.
  • Radix UI — accessible headless primitives (dialog, dropdown, tabs, tooltip, select, and more) used throughout the component library.
  • TanStack Query v5 — server-state management and API data fetching.
  • React Router v6 — client-side routing.
  • React Hook Form + Zod — form handling and schema validation.
  • @dnd-kit — drag-and-drop in the hierarchy tree and sortable surfaces.
  • Lucide React — icon set.

Analytical methods & literature

Statistical and signal-processing choices (mean confidence intervals, differentiation paths, ICA/dQ/dV conventions) are documented in the Computation report.

What does not need credit here

  • CellSeer-specific dashboard logic, metric registry, and cross-view linking — original implementation.
  • Cell identity colour system (lib/color/cellColorScheme.ts) — DJB2-hash-based hue derivation from cathode/separator/spacer strings, golden-ratio lightness ladder for replicates, circular-mean branch colours, and optional Okabe-Ito max-contrast palette. No external colour library; entirely original.
  • Cycle colour ramps (lib/color/cycleColormap.ts) — cycleColor(t) blue monotone ramp and cellCycleColor(hex, t) per-cell tint ramp. Original implementation; no rainbow or viridis colourmap libraries.
  • Standard industry patterns (REST APIs, Parquet columnar storage, MIT open-source licensing).
