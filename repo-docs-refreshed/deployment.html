Deployment

Production deployment, Docker, PostgreSQL, auth, backups, and update procedures are documented in the repository runbook — not duplicated here.

The canonical guide is DEPLOY.md at the repo root. It covers Docker Compose profiles (Caddy, Cloudflare Tunnel), environment setup, bearer-token auth, backup scripts, and the three deployment paths (Mac, cloud VM, Windows).

Local development

Run the backend on port 8000 and the Vite dev server on port 8080 (not Vite’s default 5173). The frontend proxies /api to http://127.0.0.1:8000. Stack versions and packages: Dependencies. Path-related env vars: Data model.

For Docker production builds, PostgreSQL, TLS exposure, and ops — use DEPLOY.md.
