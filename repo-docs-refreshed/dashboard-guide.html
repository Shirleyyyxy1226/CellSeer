Readiness gate

GET /api/projects/{project_id}/readiness (project_readiness() in routers/projects.py) returns:

  • hasMetadata — at least one row in cell for the project
  • metadataColumnCount — count of populated metadata columns (used as a UI quality hint)
  • cyclingFileCount — COUNT(DISTINCT cell_id) where dataset.name = 'cycling'
  • canEnterDashboard — hasMetadata && cyclingFileCount > 0

ProjectDetailPage disables Dashboard when !canEnterDashboard. Client-side gate only.

Protocol attach

AttachProtocolButton / ProtocolStatusChip launch the multi-step protocol dialog (scope → sequence → verify). See Protocol attachment.

Surface3dPlot (dV/dQ & dQ/dV 3D)

  • Camera: cameraEye + cameraSeq; uirevision forces reapply on preset/Reset
  • Footer: Profile / Evolution presets; Reset 3D → eye {x:2.3, y:1.6, z:0.95}
  • Wheel scroll isolation — {passive:false} on canvas
  • Heavy-render guard — modal when trace count >200

Colour system

  • Cell identity (cellIdentityColor): DJB2 hash of cathode; separator ±22°, spacer ±8°; replicate ±5° + lightness 38–62%
  • Branch colour: circular mean of cell hues (pathColorFromHues)
  • Replicate encoding: DASH_LADDER (6) + SYMBOL_LADDER (8) within condition group
  • Max-contrast mode: Okabe-Ito + Glasbey (16 entries) via GCD toggle
  • Cycle colours (cycleColormap.ts): cycleColor(t) blue ramp; cellCycleColor(hex, t) tints identity colour
